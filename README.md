# iFix - protótipo moderno

Protótipo estático em HTML, CSS e JavaScript com login local, cadastro separado de cliente e prestador, apresentação clara da proposta, fluxo de solicitação e identidade visual moderna em azul e amarelo.

## Recursos
- Nova tela de acesso com logo em cartão branco sobre fundo azul em degradê.
- Seção "Como funciona" e benefícios da plataforma.
- Cadastro de cliente e prestador.
- Comparação de profissionais e estimativa de preço.
- Layout responsivo.

## Publicar no GitHub Pages
Envie tudo preservando as pastas `css`, `js` e `images`. Em **Settings > Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)`.

## Importante
Os cadastros ficam apenas no `localStorage`. Não há servidor, criptografia, validação documental ou autenticação real. Use somente dados fictícios.

## Fluxo de busca demonstrativo
Após enviar uma solicitação, o protótipo abre uma tela de busca com mapa ilustrativo, solicita a geolocalização do navegador, simula as etapas de compatibilidade e mostra os profissionais encontrados. As posições dos prestadores e as distâncias continuam fictícias.
